# Licensing of the companion package

This package is released free of charge for any use, including teaching and research, under two licenses.

| Material | License | File |
|---|---|---|
| Code: `src/`, `scripts/`, `tests/`, `r/`, and the code cells of `notebooks/` | MIT | `LICENSE` |
| Data and text: `data/`, `outputs/`, `templates/`, `instructor/`, and the written parts of `notebooks/` | CC BY 4.0 | `LICENSE-DATA.txt` |

Every data object in `data/` is a synthetic teaching fixture generated by the scripts in `scripts/`. It contains no human-subject data and no material from a restricted corpus. `data/MANIFEST.tsv` records the source, license, and SHA-256 checksum of each object.

## How to cite

Ishihara, T. (2026). *Phonetic Research in Practice: Companion materials* [Computer software and data]. Version-specific citation information is in `CITATION.cff`.

## Scope

The license applies to this package only. It does not cover the book text, which is published separately, and it does not authorize redistribution of any third-party corpus that a learner applies the code to.
